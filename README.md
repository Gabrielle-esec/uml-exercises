# UML Modeling Exercises

A collection of UML modeling exercises completed as part of my Object-Oriented Programming studies.

These projects explore how to translate business requirements into object-oriented system designs using UML diagrams.

## Projects

### 1. Hospital Management System

Design of an online platform connecting patients, doctors, and organizers.

**Topics covered:**
- Class diagrams and inheritance
- Associations and multiplicities
- Health problems and medical consultations
- Prescription management and history
- Payment processing with the Strategy Pattern
- Sequence diagrams for registration, consultation, and payment

**Files:**
- [Class Diagram](01-hospital-management/class-diagram.md)
- [Sequence Diagrams](01-hospital-management/sequence-diagrams.md)
- [Design Decisions](01-hospital-management/design-decisions.md)

### 2. ABCD Records

Design of a mail-order management system for CDs and tapes, with Regular and Royal memberships.

**Topics covered:**
- Use case diagrams
- Class diagrams and inheritance
- Order and inventory management
- Royal membership discounts and backorders
- Payment processing (cash, check, bank draft)
- Sequence diagrams for ordering, stock verification, and payment

**Files:**

## UML Concepts Practiced

| Concept | Description |
|---------|-------------|
| Class Diagram | Models classes, attributes, methods, and relationships |
| Use Case Diagram | Represents system functionality and actors |
| Sequence Diagram | Shows interactions between objects over time |
| Inheritance | Shares common properties and behaviors |
| Association | Connects related objects |
| Composition | Represents strong ownership relationships |
| Multiplicity | Defines how many objects can participate in a relationship |
| Polymorphism | Allows different implementations of shared behavior |
| Strategy Pattern | Encapsulates interchangeable algorithms |
